Gossip Tales 2

A escape-room-like game where you find yourself in the center of high school drama. This time, though, you are seeing things through Ava's eyes.

------
I created this because I realized I kind of left the last game on a cliffhanger and I thought it'd be interesting to create a sequel of Gossip Tales since it was pretty unhinged. This is also super fun to make and I was super proud of the result (especially after only 4 hours of coding as it was for Snoozefest and I procrastinated 😓)

------
I made this with HTML, CSS, and JS. I used divs, modals, and animations a lot. I also used some images as icons, specifically the "next" arrow and the "replay" button. There's also a lot of hover animations with the buttons, links, and images. In terms of order, I worked my way towards the ending: For example, I started with index.html, then moved to situation.html (Ava's past), then situation-2.html, suspects.html, and onwards.

------
I knew that this one would be the same as the other Gossip Tales game I made, so I wanted to challenge myself with things like multiple modals (this killed me) and animations. These two things were the main challenges in this project. One thing I'm really proud of, though, is how I thought of the end scene idea so creatively :) I made it a modal and then added animations later, instead of a whole new page (that would be boring and I wouldn't be able to animate it as interestingly). It turned out super cool!
